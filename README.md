# avatar-production-lab

無料ツールを中心に、Blenderでアバターを制作するための知見を整理する資料集です。形、陰影、テクスチャ、表情、書出しの各工程を、出典と検証状態を付けて記録します。

## 読み始める場所

- [制作工程と比較方法](docs/workflow.md)
- [無料ツールの選定と対応状況](docs/free-tools.md)
- [論文・実制作から応用できる知見](docs/research-notes.md)

## 現在の範囲

初期版は文書のみです。モデル、テクスチャ、個別キャラクターの画像、実行スクリプトは同梱しません。記事で紹介するアドオンは自動でインストールしません。

資料上の対応、手元での動作、VRM・VRChat等の出力先での実機確認を区別します。掲載した全ツールや工程の動作保証はありません。各文書の確認日と未検証範囲を参照してください。

## 個別制作との分担

ここでは別のキャラクターにも適用できる方法を扱います。キャラクター固有の形状、材質、カメラ設定、制作原本は個別の制作リポジトリで管理します。共通スクリプトは実際の再利用が確認できてから追加し、利用側は採用する版を固定します。
